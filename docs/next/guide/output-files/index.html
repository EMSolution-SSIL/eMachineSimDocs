出力ファイルと診断

eMachineSim は CSV diagnostics と post-processing files を出力します。CSV は scripted check や収支確認に使い、.vtk, .atl, .neu, .mm, plain text output は可視化やデバッグ確認に使います。

解析結果の要約: output.json​

熱伝導・熱等価回路連成、静的構造、固有モード解析では、実行フォルダに機械可読な output.json を出力します。metaData、analysisCondition、postProcessing の各キーを持ち、Python から重要な評価値を直接確認できます。EMSolution の output.json と構成の考え方を合わせていますが、キーの詳細は eMachineSim 固有です。

この機能は 0.2.0 版で追加されました。0.1.1 wheel では output.json は出力されません。

解析postProcessing の内容
熱伝導・熱等価回路連成temperatureByProperty に property ID 別の minimum、maximum、average (degC)、節点数・要素数
静的構造・遠心力displacementMagnitude.maximum と vonMisesStress.maximum、位置の node/element ID
固有モードmodes に各 mode の周波数と maximumDisplacementMagnitude、node ID、正規化方法

熱の集計対象は解析に含まれる有限要素の節点です。各 property に属する要素の節点 ID を重複除去してから最小・最大・算術平均を求めます。共有節点は所属する双方の property に含まれます。BDF 入力では元の property ID を使用し、除外した空気領域などは含めません。平均は体積加重平均ではありません。熱等価回路のみの node 温度は従来どおり thermal_network_nodes.csv で確認します。

静的構造の vonMisesStress.maximum は、2D では要素中心、3D ソリッドでは積分点で求めた応力の最大値です。location で評価位置を区別し、3D では integrationPoint も出力します。elementId はその要素、elementCount は集計した要素数です。3D の vonMisesStressByProperty は領域ごとの最大値と要素 ID、積分点、要素数を含みます。propertyId は BDF 入力では元の property ID、neutral mesh では材料 ID です。応力を計算できない場合は available: false となります。displacementMagnitude.maximum は節点変位ベクトルの大きさの最大値です。入力座標を SI の m (UNIT: 0)、弾性率を Pa で指定した例では、変位は m、応力は Pa です。

固有モードの modes は modeId、frequencyHz、maximumDisplacementMagnitude、nodeId、normalization を含みます。最大変位は固有ベクトルの正規化振幅で、運転時の物理的な変位量ではありません。異なるモードの絶対振幅を運転変位として比較しないでください。normalization: "mass" は質量正規化を示します。周波数応答や音響指標のピーク値は、この modes の集計対象ではありません。

import json
from pathlib import Path

data = json.loads(Path("output.json").read_text(encoding="utf-8"))
for region in data["postProcessing"]["temperatureByProperty"]:
    print(region["propertyId"], region["maximum"], region["average"])

遠心力解析と固有モード解析では、同じ output.json から次のように取得します。

import json
from pathlib import Path

data = json.loads(Path("output.json").read_text(encoding="utf-8"))
post = data["postProcessing"]
if data["analysisCondition"]["analysisType"] == "structural_static":
    stress = post["vonMisesStress"]
    if stress["available"]:
        print(stress["maximum"], stress["elementId"])
    print(post["displacementMagnitude"]["maximum"])
elif data["analysisCondition"]["analysisType"] == "structural_modal":
    for mode in post["modes"]:
        print(mode["modeId"], mode["frequencyHz"],
              mode["maximumDisplacementMagnitude"], mode["nodeId"])

数値を再計算した代表例は ロータの遠心力解析 と モータ NVH・固有モード解析 を参照してください。

VTK visualization notes​

現在の出力では VTK post files は自動的に出力されます。追加の input parameter は不要です。ParaView で .vtk を開き、mesh、boundary faces、temperature、potential、displacement、von Mises stress、mode shape などを確認してください。
