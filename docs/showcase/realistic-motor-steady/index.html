Realistic Motor Steady Thermal Sample

この showcase は、混在 CHEXA/CPENTA BDF mesh、BDF QVOL loss、JSON で追加する coil copper loss / PM loss、FEMH surface cooling、thermal equivalent circuit、stator/rotor gap coupling を組み合わせたモータ定常熱解析サンプルです。 目的は実測温度に合わせることではなく、損失入力、境界条件、熱等価回路、gap coupling、CSV diagnostics を確認することです。 公開サンプルは次のフォルダにあります。

Examples/thermal/realistic_motor_steady/

BDF は同じフォルダ内の次のファイルです。

Examples/thermal/realistic_motor_steady/QVOL_loss_mix.bdf

Model and mesh​

この mesh は thermal conduction model として使用します。BDF から element geometry、property ID、bulk section、QVOL heat source を読み込みます。coil copper loss と PM loss は JSON から追加します。

Thermal equivalent circuit​

この図は、FEM thermal mesh と thermal equivalent circuit の接続概念を示しています。stator 側の主な発熱は stator external surface から FEMH port を通って housing node へ流れ、housing から mount、ambient へ熱抵抗で流れます。rotor 側の熱は rotor external surface から shaft node へ接続され、shaft、bearing、ambient 側へ流れます。

  • FEMH-S: stator external surface から housing への接続
  • FEMH-R: rotor external surface から shaft への接続
  • G-gap: stator / rotor gap surface coupling
  • R-HM, R-MA, R-SB, R-BA: thermal network resistance path

Gap surface は外部 FEMH cooling surface と重複させず、G-gap の surface-to-surface coupling として扱います。FEMH port、thermal resistance、network node の熱流と温度は thermal_cooling_path_summary.csv、thermal_femh_ports.csv、thermal_network_nodes.csv で確認できます。

Temperature result​

温度絶対値は仮の境界条件に依存します。重要なのは、loss total、heat balance、surface overlap、cooling path を CSV で確認できることです。

Gap area result​

Gap coupling に使う面は、外部 FEMH cooling surface から除外します。thermal_surface_assignment_summary.csv で femh_and_gap_overlap area = 0 を確認してください。
