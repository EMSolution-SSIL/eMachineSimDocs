3D 全周リングの構造・固有モード解析

このサンプルは、電気機器の回転部を簡略化した全周 3D リングを使い、遠心力による変位と応力、および拘束されたリングの固有モードを確認します。0.2.0 以降の wheel 向けであり、0.1.1 wheel には 3D 応力・固有モードの追加機能は含まれません。材料値と寸法は検証用で、実機モータの予測値ではありません。

公開入力とメッシュは Examples/structural/ring/ にあります。元の 90 度メッシュではなく、全周の pre_geom.neu を解析に使用します。

モデルとメッシュ​

内半径 0.5 m、外半径 1.0 m、軸方向長さ 0.5 m のリングです。メッシュは 2016 節点、1296 個の HEXA8 体積要素で構成され、内周の 288 節点を X/Y/Z の全方向で固定します。これはシャフト側を固定した単純化モデルであり、自由支持リングの結果とは異なります。

材料は線形等方弾性で、E = 210 GPa、nu = 0.3、rho = 7800 kg/m3 です。入力座標の単位は m、応力は Pa、変位は m で扱います。回転と材料は説明用の条件であり、応力集中や支持剛性を含む実機評価にはモデルを作り直してください。

遠心力による静解析​

input_ring_static.json では Z 軸回りに角速度 100 rad/s を与えます。コイルや磁石などの別部品は含まず、リングの遠心体積力を計算します。内周拘束はモード解析と共通です。

評価量結果
最大変位ベクトル長3.1351e-5 m (約 31.4 µm)
最大ミーゼス応力2.6232e7 Pa (約 26.2 MPa)
最大応力の位置要素 ID 115、積分点 27

内周付近に高い応力が現れます。この図の VTK cell 値は各要素の積分点のうちミーゼス応力が最大の点を示し、節点へ平均化した値ではありません。最大値はメッシュと拘束条件に依存するため、設計許容応力との比較にはメッシュ収束と支持条件の検討が必要です。

内周面圧による静解析​

input_ring_pressure.json は遠心力を使わない一般的な荷重例です。外周の 288 節点を X/Y/Z 全方向に固定し、内周の円筒面に一様な 1 MPa の面圧を与えます。遠心力ケースとは固定位置が異なり、荷重が作用する内周は自由に変位できます。

"STRUCTURAL_SURFACE_PRESSURES": [
  {"PRESSURE": 1000000, "R_MAX": 0.6, "Z_MIN": 0.001, "Z_MAX": 0.499}
]

R は XY 平面で原点から測る半径です。指定した範囲で境界面の重心を判定し、端面を除いた内周 216 面だけを選びます。SMAT_ID が付いていないメッシュでも指定可能です。正の面圧は境界の外向き法線と逆向きに作用するため、内側の穴では材料側へ押し広げます。面の選択が 0 件の場合はエラーになります。

評価量結果
最大変位ベクトル長1.5685e-6 m (約 1.57 µm)
最大ミーゼス応力1.1047e6 Pa (約 1.10 MPa)

全周対称のため、structural_load_balance.csv に示される面圧の合力はほぼゼロです。これは面圧や局所応力がゼロという意味ではありません。拘束や半径に依存する検証値であり、実機の内圧評価には支持条件とメッシュ収束を確認してください。

3D 固有モード解析​

input_ring_modal.json では同じ内周拘束と材料を使い、整合質量行列と疎固有値ソルバーで最初の 4 モードを求めます。このケースに遠心力や回転時の初期応力は含めていません。したがって回転中の遠心応力を考慮した固有振動数ではありません。

モード固有振動数
11015.07 Hz
21024.80 Hz
31024.80 Hz
41050.15 Hz

図はモード 2 の質量正規化された変位を表示用に 8 倍して描いたものです。色は正規化モード振幅であり、実運転時の変位ではありません。モード 2 と 3 はこの対称モデルでほぼ同じ周波数になります。2D sector 専用の modal_modes_cyclic_full.vtk はこの 3D 全周モデルには出力しません。

実行と結果の確認​

0.2.0 以降の eMachineSim Python モジュールと対応ライセンスを用意し、公開リポジトリのルートから実行します。

python Examples/structural/ring/run_ring.py --output-dir ring_results

内圧ケースは ring_results/pressure/ に出力されます。output.json、structural_displacement.vtk、structural_load_balance.csv で結果と荷重の合力を確認できます。

ring_results/static/ の structural_displacement.vtk と output.json で変位・応力を確認します。output.json の postProcessing.vonMisesStressByProperty はこの neutral mesh では材料 ID を propertyId として使います。ring_results/modal/ の modal_frequencies.csv、modal_modes.vtk、output.json で周波数とモード形状を確認します。両解析は別ディレクトリへ出力されるため、結果を上書きしません。

この全周モデルは小モデルより実用的な入力・出力確認に適していますが、解析解や実測値との精度照合、メッシュ収束、3D 強制振動応答は未実施です。コイルエンドの周期的な電磁力や EMSOptimizer 連携を実証した例ではありません。
