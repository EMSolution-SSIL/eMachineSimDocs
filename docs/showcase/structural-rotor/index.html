Structural Rotor Samples

この showcase は、eMachineSim の rotor structural sample を説明します。遠心力を受ける rotor design workflow で、shaft/support constraint、変位、von Mises stress、簡易 contact diagnostics を確認するためのサンプルです。 公開サンプルは次のフォルダにあります。

Examples/structural/rotor/

代表 JSON は次の通りです。

input_rotor_2d_1500rpm_smoke.json
input_rotor_2d_3000rpm_smoke.json
input_rotor_2d_1500rpm_shaft_bc_no_contact.json
input_rotor_core_only_2d_1500rpm.json
input_rotor_core_only_2d_modal.json
ヒント

一次要素の入力メッシュでも、6_Gaussian_Integral_Point の "ELEMENT_ORDER": 2 を指定すると、読み込み後の前処理で内部的に二次要素へ変換して解析できます。変換後のポスト処理メッシュも二次要素として出力されます。

Model description​

この例では 2D rotor cross-section model を使います。rotor core、magnet region、flux-barrier boundary、centrifugal-force load case 用の structural boundary condition を含みます。 現在の公開 mesh では、永久磁石と rotor core の interface は shared-node merged interface として扱います。これは、磁気吸引により磁石が rotor core に保持されているという基本仮定を表します。

主な merged-mesh case は次の入力です。

Sector model constraints​

45度、90度、120度、180度などの部分モデルでは、STRUCTURAL_CYCLIC_SECTOR_BC により角度最小側と角度最大側の周期境界面を自動抽出できます。 遠心力解析では、通常は径方向変位を許容し、周方向変位を拘束します。

シャフトを mesh 化していない inner rotor model では、STRUCTURAL_RADIAL_SUPPORT_BC を使ってシャフト接触内面を簡易的に支持できます。 この条件は、境界節点から周期境界面の節点を除外し、SIDE: "INNER" の場合は最小半径の節点列を抽出して、指定した円筒座標方向の拘束を penalty 法で与えます。

代表的な 45度 sector model の指定例は次の通りです。

"STRUCTURAL_CYCLIC_SECTOR_BC": {
  "ENABLED": 1,
  "AUTO_DETECT": 1,
  "AXIS_POINT": [0.0, 0.0, 0.0],
  "MIN_RADIUS": 1e-8,
  "FIX_RADIAL": 0,
  "FIX_TANGENTIAL": 1,
  "FIX_UZ": 0,
  "PENALTY_STIFFNESS": 1e15
},
"STRUCTURAL_RADIAL_SUPPORT_BC": {
  "ENABLED": 1,
  "AUTO_DETECT": 1,
  "SIDE": "INNER",
  "AXIS_POINT": [0.0, 0.0, 0.0],
  "EXCLUDE_CYCLIC_SECTOR_NODES": 1,
  "RADIUS_TOLERANCE_ABS": 1e-6,
  "RADIUS_TOLERANCE_REL": 1e-4,
  "FIX_RADIAL": 1,
  "FIX_TANGENTIAL": 0,
  "FIX_UZ": 0,
  "PENALTY_STIFFNESS": 1e15
}

解析時には structural_cyclic_sector_constraints.csv と structural_radial_support_constraints.csv が出力され、抽出された節点、半径、角度、拘束方向を確認できます。

Result plot​

変形図と von Mises stress は structural_displacement.vtk で確認できます。ParaView では displacement vector を Warp By Vector に指定し、stress distribution を表示します。

注記

この showcase の mesh は磁界解析用 mesh を流用しています。そのため、応力が集中する箇所では mesh が粗く、局所的な高応力が出る可能性があります。実際の設計評価では、応力分布に合わせたより細かい mesh で解析することをおすすめします。
